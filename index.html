For non-developers

Steer the agent in plain English. With guardrails.

No code, no config syntax. A non-technical user edits one plain-language file and the agent changes its behavior and its tone. The safety rails are written in code, not in the file — so an ambiguous instruction can never become a silent mistake.

family.md — edit this in plain EnglishWe're in US Eastern time. "Practice" means soccer practice unless it says otherwise. Sebastian's events are the priority. Never put anything before 8:00 AM — flag it if it's earlier. Keep your summaries brief and friendly. For clean, obvious events, just add them — don't ask me every time.
  • It can raise caution. "Just add clean events" is honored — but only for events that are actually clean.
  • It can't lower the floor. A shaky date, a conflict, or a duplicate always comes back to you — whatever the file says.
  • It never guesses. No confident-but-wrong dates. Ever.
⚠ STEERING: starts at 07:00 AM, before your 08:00 cutoff

Even with "auto-add" on, this 7am event is held back for you — because you also said nothing before 8am, and the agent honors the more cautious instruction. That's the senior-developer judgment, baked in.

For builders

Built to be worked on by other people.

The structure is the strategy. One strict contract, a boundary the engine never crosses, and stubs your teammates can claim — so several people can build in parallel without colliding.
